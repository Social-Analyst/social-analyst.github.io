# Social Analyst — GitHub Pages site

Public landing page. Submits Instagram usernames to the Lovable backend, polls for results, displays them.

## Deploy on GitHub Pages

1. Edit `config.js` and set `API` to your published Lovable backend URL (e.g. `https://your-app.lovable.app`).
2. Create a new GitHub repo, drop these 4 files in (`index.html`, `config.js`, `app.js`, `README.md`).
3. Settings → Pages → Source: `main` branch, `/ (root)`. Save.
4. Visit `https://<you>.github.io/<repo>/`.

That's it. The backend handles everything else.
